## 1. 目的

このファイルは色・写真・最終コピーを決めるものではない。

以下を固定する。

- 画面上の情報優先順位
- 検索流入後の最短導線
- スポンサーと本文の分離
- PC / Mobileでの情報配置
- 比較UI
- 店舗詳細アクセスUI
- GA4計測ポイント

上部の電話CTAがスクロールで画面外へ出た後のみ、

- safe-area対応

# 13. 簡易アクセスマップ

```text
       ○○小学校
           │
○○通り ── ● 店舗
           │
        ○○通り
           │
      ○○バス停
```

要件:
- 「簡易案内図」と明示
- 正確な縮尺に見せない
- SVGまたはHTML/CSS
- 店舗・主要道路・ランドマーク2〜4件
- 同内容を本文テキストでも表示
- Googleマップは補助リンク


### フォールバック

十分なランドマークを確認できない場合:

```text
アクセス
住所: 三鷹市○○
最寄り: ○○（確認済みの場合）
アクセスメモ: ○○（確認済みの場合）

[Googleマップで正確な場所を開く]
```

模式図を作るために位置関係を推測しない。


### モード選択

`simple_map` / `text_only`は運営者が店舗ごとに明示指定する。
自動生成・自動判定は行わない。

# 22. ワイヤーフレーム Acceptance Criteria

- [ ] 全ページでH1が早い位置にある
- [ ] 検索流入ページはQuick Answerを持つ
- [ ] 店舗へ進む導線が本文後半だけにない
- [ ] PC左右スポンサーが中央本文を圧迫しない
- [ ] Mobileでスポンサーを比較内に混在させない
- [ ] 比較はPC表 / Mobileカード
- [ ] 店舗詳細に簡易アクセス案内
- [ ] Googleマップ埋め込みを主役にしない
- [ ] 電話・公式HP・アクセスを計測可能
- [ ] 未確認情報が視覚的に分かる
