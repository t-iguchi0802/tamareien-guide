# 多磨霊園 お墓ガイド｜AI継続運用計画

## 目的

公開後のサイトを放置せず、最新情報、アクセスデータ、検索状況、掲載店情報を定期的に確認し、根拠のある改善を続ける。

## 担当と頻度

| 担当エージェント           | 頻度              | 主な入力                   | 成果物                  |
| -------------------------- | ----------------- | -------------------------- | ----------------------- |
| `tama-news-monitor`        | 毎週2回（月・木） | 東京都公園協会等の公式発表 | TOP最新情報の更新案・PR |
| `analytics-reporter`       | 毎週月曜・毎月1日 | GA4、Search Console        | 週次速報、月次分析      |
| `seo-reviewer`             | 毎月3日           | 月次分析、現在のサイト     | 翌月の改善案3件以内・PR |
| `business-listing-monitor` | 毎月15日          | 事業者公式情報、商工会等   | 掲載情報の更新案・PR    |

## 実行の流れ

1. 各担当が読み取りと確認を行う。
2. 事実と解釈を分けた報告を作る。
3. 公開内容を変える場合は、出典付きの変更案またはPRを作る。
4. `check`、`lint`、`build`が成功した変更だけを公開候補にする。
5. 承認後に`integrated-mvp`へ反映し、Cloudflareの公開結果を確認する。

## 自動実行に必要なもの

Claude Codeのサブエージェント定義だけでは、指定日時に自動起動しない。定期実行にはGitHub Actions等のスケジューラーと、利用するAI/APIの認証設定が必要になる。

### GA4・Search Console

- 読み取り専用サービスアカウント
- GA4プロパティID
- Search Consoleプロパティ `sc-domain:tamareien-guide.jp`
- 認証情報はGitHub Secrets等で管理し、コード・ログ・公開レポートへ書かない

### レポートの保管

このGitHubリポジトリは公開されているため、検索語、アクセス数、スポンサー別実績などの運営データはコミットしない。非公開の運用先に保存する。

## 公開の安全策

- ニュース、掲載店情報、SEO本文を無確認で自動公開しない。
- 期限切れのお知らせはビルド時にも非表示にする。
- 公式情報が取れなかった場合は更新せず、要確認として報告する。
- アクセス解析エージェントはサイト本文を編集しない。
- 一度に大量のタイトル・URLを変更しない。
